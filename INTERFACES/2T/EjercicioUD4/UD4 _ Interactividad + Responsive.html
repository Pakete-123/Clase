Bienvenido/a

Esta página sirve para practicar interactividad con JavaScript, carga de scripts (async/defer) y diseño responsive con media queries.

Información adicional

Aquí aparecerá contenido extra. El objetivo es mostrar/ocultar este bloque con JavaScript, cambiando también el texto del botón.

¿Para qué sirve defer?

Para ejecutar un script después de que el DOM esté listo (ideal si el script manipula elementos).

¿Para qué sirven las media queries?

Para adaptar el diseño a móviles/tablets/escritorio mejorando la experiencia de usuario.
