Objetivo

Esta página tiene varios scripts. Tu trabajo es diseñar la experiencia de carga: decidir qué scripts deben cargarse con async o defer para mejorar la usabilidad y el rendimiento percibido.

Consejo: abre DevTools → Console. Luego prueba DevTools → Network → Slow 3G.

Mensaje de bienvenida.

Zona interactiva

Los botones se activan cuando la interfaz está lista. Si ves errores o tarda demasiado en activarse, revisa cómo se están cargando los scripts.

Estado: cargando…

Este bloque se muestra/oculta. Sirve para comprobar si un script que toca el DOM necesita defer.

Checklist (rápido)

  • ¿Desaparece el overlay de carga en el momento adecuado?
  • ¿Los botones se activan cuando deben?
  • ¿Hay errores en la consola?
  • ¿La web se siente “rápida” en Slow 3G?
