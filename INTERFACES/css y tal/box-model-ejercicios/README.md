# Modelo de Cajas — Ejercicios con Conmutadores

Abre `index.html` en tu navegador. Usa los botones para activar cada ejercicio y observa el efecto en el **box model** con las DevTools.

## Contenido
- `index.html`: Página interactiva con conmutadores (1–15).
- `styles.css`: Estilos base y clases para cada ejercicio.

## Sugerencias de uso
1. Abre DevTools (F12) → pestaña **Elements** → panel **Layout/Box Model**.
2. Activa un ejercicio y examina `margin`, `border`, `padding` y `content`.
3. Cambia propiedades en vivo desde DevTools y anota diferencias.
