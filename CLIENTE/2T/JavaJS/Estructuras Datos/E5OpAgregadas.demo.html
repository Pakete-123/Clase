Demo — OpAgregadas.js

Operaciones agregadas sobre arrays numéricos: filter, map y reduce para filtrar, transformar y acumular resultados.

Cómo funciona

  1. Este HTML captura console.log y lo muestra en el panel de salida.
  2. Al pulsar Ejecutar, inyecta OpAgregadas.js con un parámetro temporal para forzar recarga y repetir la ejecución.
  3. También puedes inspeccionar la salida en la consola del navegador.

Cómo probar

  1. Coloca este HTML en la misma carpeta que OpAgregadas.js.
  2. Abre el HTML en el navegador (doble clic).
  3. Asegúrate de tener definido un array notas (ej.: const notas = [6, 8, 5, 4, 7];), pulsa Ejecutar y observa la salida.
